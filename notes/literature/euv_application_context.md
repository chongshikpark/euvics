# EUV source requirements and application context

## Sources reviewed

- `NISTEUVDetectorCalibration` — authoritative NIST metrology service description.
- `VanDenBoogaardEtAl2012EUVMirror` — primary 13.5 nm multilayer-grating experiment.

## Supported paraphrase

EUV radiometry requires wavelength-dependent detector calibration, and EUV
multilayer optical performance is wavelength-, sample-, and geometry-specific.

## EUVICS inference and limits

Neither source defines EUVICS application requirements. Wavelength, bandwidth,
flux, brilliance, stability, polarization, availability, and interface requirements
must come from an authoritative sponsor/application source. A single measured
mirror reflectance may not be multiplied into an EUVICS transport budget without
the selected coating, incidence distribution, contamination state, and uncertainty.
