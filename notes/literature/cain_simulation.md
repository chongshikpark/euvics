# CAIN and related simulation tools

## Source reviewed

- `YokoyaCAINManual` — author-issued CAIN user manual identifying software inputs and operation.
- `SunWu2011ComptonSource` — independent analytical/Monte Carlo Compton-source methods.

## Supported paraphrase

CAIN is a configurable beam-interaction simulation code, and Compton-source
observables depend on model inputs, geometry, polarization, collimation, binning,
and statistics.

## EUVICS inference and limits

The repository contains no CAIN version, executable checksum, input deck, output,
or matched comparison. Therefore no agreement between pyEUVICS and CAIN is
claimed. A future comparison must match energy convention, geometry, acceptance,
polarization, harmonic/recoil treatment, binning, random statistics, and uncertainty.
