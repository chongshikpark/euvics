# Figure review checklist

- [ ] The figure is original, licensed, or permitted for the intended distribution.
- [ ] Source data and generation scripts are identified and versioned.
- [ ] Configuration, software version, units, warnings, seed, sample count, and input checksums are preserved where applicable.
- [ ] Axes, legends, symbols, units, width conventions, angles, and acceptance are defined.
- [ ] The caption states what is shown, relevant conditions, and the supported conclusion.
- [ ] Numerical content agrees with reviewed tables and generated macros.
- [ ] The figure remains legible at final document size and in grayscale when required.
- [ ] The document builds with the figure from a clean checkout.
